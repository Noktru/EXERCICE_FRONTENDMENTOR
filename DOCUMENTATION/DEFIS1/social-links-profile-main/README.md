# Frontend Mentor - Profil de liens sociaux

![Aperçu du design pour le défi de profil de liens sociaux](./preview.jpg)

## Bienvenue ! 👋

Merci d’avoir regardé ce défi de développement front-end.

Les défis [Frontend Mentor](https://www.frontendmentor.io) vous aident à améliorer vos compétences en construisant des projets réalistes.

**Pour ce défi, il vous faut une compréhension de base du HTML et du CSS.**

## Le défi

Votre challenge consiste à réaliser ce profil de liens sociaux et à le rendre aussi proche que possible du design.

Vous pouvez utiliser tous les outils que vous souhaitez pour terminer le défi. Donc, si vous souhaitez pratiquer quelque chose, n’hésitez pas à vous lancer.

Vos utilisateurs doivent pouvoir :

- Voir les états au survol et au focus pour tous les éléments interactifs de la page

### Vous voulez un peu d’aide pour le défi ?

[Rejoignez notre communauté](https://www.frontendmentor.io/community) et posez vos questions dans le canal **#help**.

## Où trouver tout ce qu’il faut

Votre tâche consiste à créer le projet selon les maquettes dans le dossier `/design`. Vous y trouverez une version mobile et une version desktop.

Les maquettes sont au format JPG statique. Cela signifie que vous devrez utiliser votre jugement pour des styles comme `font-size`, `padding` et `margin`.

Si vous souhaitez obtenir le fichier Figma et gagner de l’expérience avec des outils professionnels pour créer des projets plus précis plus rapidement, vous pouvez [vous abonner en tant que membre PRO](https://www.frontendmentor.io/pro).

Tous les éléments nécessaires à ce projet se trouvent dans le dossier `/assets`. Les images sont déjà exportées à la bonne taille et optimisées.

Nous incluons également des fichiers de polices variables et statiques pour les polices requises. Vous pouvez soit utiliser Google Fonts, soit héberger les polices vous-même avec les fichiers locaux. Notez que nous avons retiré les fichiers statiques des graisses de police qui ne sont pas nécessaires pour ce projet.

Il existe aussi un fichier `style-guide.md` contenant les informations dont vous aurez besoin, comme la palette de couleurs et les polices.

## Utiliser des assistants de codage IA

Nous avons inclus deux fichiers pour vous aider si vous utilisez des assistants de codage IA (comme Claude, GitHub Copilot, Cursor, etc.) pendant ce défi :

- `AGENTS.md` - Contient des instructions détaillées pour les assistants IA afin de vous aider dans ce défi. Il est adapté au niveau de difficulté de ce défi, donc l’IA fournira un accompagnement adapté à votre niveau d’apprentissage — avec davantage d’aide pour les défis de débutant et plus d’autonomie pour les défis plus avancés.
- `CLAUDE.md` - Un fichier de référence qui dirige les outils basés sur Claude vers les instructions de AGENTS.md.

**Comment les utiliser :** Vous n’avez rien à faire ! Ces fichiers sont détectés automatiquement par la plupart des outils d’IA. L’IA les lira et ajustera son comportement pour devenir un meilleur partenaire d’apprentissage — en vous guidant vers des solutions plutôt que de vous donner directement les réponses.

**Remarque :** Ces fichiers sont conçus pour vous aider à *apprendre*, pas pour faire le travail à votre place. L’IA reçoit l’instruction de poser des questions, donner des indices et expliquer les concepts plutôt que d’écrire des solutions complètes.

## Créer votre projet

N’hésitez pas à utiliser le workflow qui vous convient le mieux. Ci-dessous, vous trouverez une méthode suggérée, mais vous n’êtes pas obligé de suivre ces étapes :

1. Initialisez votre projet en tant que dépôt public sur [GitHub](https://github.com/). Créer un dépôt facilitera le partage de votre code avec la communauté si vous avez besoin d’aide. Si vous n’êtes pas sûr de la procédure, [consultez cette ressource Try Git](https://try.github.io/).
2. Configurez votre dépôt pour publier votre code sur une adresse web. Cela sera aussi utile si vous avez besoin d’aide pendant un défi, car vous pouvez partager l’URL de votre projet ainsi que l’URL de votre dépôt. Il existe plusieurs façons de le faire, et nous vous proposons quelques recommandations ci-dessous.
3. Parcourez les maquettes pour commencer à planifier la façon de traiter le projet. Cette étape est cruciale pour anticiper les classes CSS à créer afin d’avoir des styles réutilisables.
4. Avant d’ajouter des styles, structurez votre contenu en HTML. Écrire d’abord le HTML peut vous aider à vous concentrer sur la création d’une structure bien organisée.
5. Rédigez les styles de base de votre projet, y compris les styles généraux du contenu, comme `font-family` et `font-size`.
6. Commencez à ajouter des styles en haut de la page et descendez progressivement. Ne passez à la section suivante que lorsque vous êtes satisfait de la zone que vous avez terminée.

## Déployer votre projet

Comme mentionné ci-dessus, il existe de nombreuses façons d’héberger votre projet gratuitement. Nos hébergeurs recommandés sont :

- [GitHub Pages](https://pages.github.com/)
- [Vercel](https://vercel.com/)
- [Netlify](https://www.netlify.com/)

Vous pouvez héberger votre site via l’une de ces solutions ou tout autre fournisseur fiable. [Lisez davantage sur nos hébergeurs recommandés et fiables](https://www.frontendmentor.io/guides/hosting-your-solution).

## Créer un `README.md` personnalisé

Nous recommandons fortement de remplacer ce `README.md` par un fichier personnalisé. Nous avons fourni un modèle dans le fichier [`README-template.md`](./README-template.md) de ce code de départ.

Le modèle sert de guide pour ce qu’il faut ajouter. Un `README` personnalisé vous aidera à expliquer votre projet et à réfléchir sur ce que vous avez appris. N’hésitez pas à modifier ce modèle autant que vous le souhaitez.

Une fois que vous aurez ajouté vos informations dans le modèle, supprimez ce fichier et renommez `README-template.md` en `README.md`. Cela fera apparaître le fichier dans le README de votre dépôt.

## Soumettre votre solution

Soumettez votre solution sur la plateforme pour que le reste de la communauté puisse la voir. Suivez notre ["Guide complet pour soumettre des solutions"](https://www.frontendmentor.io/guides/how-to-submit-solutions) pour obtenir des conseils.

N’oubliez pas que si vous cherchez des commentaires sur votre solution, demandez des questions lors de la soumission. Plus vos questions seront spécifiques et détaillées, plus vous aurez de chances d’obtenir des retours utiles de la communauté.

## Partager votre solution

Il existe plusieurs endroits où vous pouvez partager votre solution :

1. Partagez votre page de solution dans le canal **#finished-projects** de notre [communauté](https://www.frontendmentor.io/community).
2. Partagez-la sur [X (anciennement Twitter)](https://x.com/frontendmentor) et mentionnez **@frontendmentor**, en incluant le dépôt et les URLs du site dans votre message. Nous aimerions beaucoup voir ce que vous avez construit et contribuer à le faire connaître.
3. Partagez votre solution sur [LinkedIn](https://www.linkedin.com/company/frontend-mentor/).
4. Écrivez un article sur votre expérience dans la création de votre projet. Raconter votre workflow, les choix techniques et expliquer votre code est une excellente manière de consolider ce que vous avez appris. Des plateformes comme [dev.to](https://dev.to/), [Hashnode](https://hashnode.com/) et [CodeNewbie](https://community.codenewbie.org/) sont très bien adaptées.

Nous mettons à disposition des modèles pour vous aider à partager votre solution une fois qu’elle a été soumise sur la plateforme. N’hésitez pas à les modifier et à inclure des questions précises si vous cherchez des retours.

Plus vos questions seront précises, plus il est probable qu’un autre membre de la communauté vous réponde.
