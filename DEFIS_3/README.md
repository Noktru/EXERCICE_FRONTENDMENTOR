# Carte de prévisualisation d'article

Une carte de prévisualisation d'article réalisée dans le cadre d'un défi [Frontend Mentor](https://www.frontendmentor.io/).

L'objectif de ce projet était de reproduire une carte d'article moderne, tout en proposant une mise en page responsive adaptée aux différentes tailles d'écran.

## Aperçu

La page présente :

- une illustration liée à l'article ;
- une catégorie « Learning » ;
- la date de publication ;
- un titre sur les bases du HTML et du CSS ;
- une description de l'article ;
- l'avatar et le nom de son auteur ;
- une mise en page responsive pour mobile, tablette et ordinateur.

## Technologies utilisées

- HTML5 sémantique ;
- CSS3 ;
- Flexbox ;
- Media queries ;
- unités relatives `rem` ;
- police [Figtree](https://fonts.google.com/specimen/Figtree) proposée par Google Fonts ;
- images SVG et WebP.

## Mise en page

Le fond jaune met en valeur la carte blanche contenant les informations de l'article. La carte possède une bordure noire, des angles arrondis et une ombre portée décalée qui rappelle le design original du défi.

La mise en page est réalisée avec Flexbox. La carte est centrée horizontalement et verticalement grâce à une hauteur minimale basée sur la taille de l'écran.

Des media queries permettent d'adapter progressivement les dimensions de la carte, les tailles de texte et les espacements sur les écrans de différentes largeurs.


## Ce que j'ai appris

Pendant la réalisation de ce projet, j'ai appris à créer une carte de prévisualisation d'article avec une structure HTML sémantique et une mise en page organisée.

J'ai également approfondi l'utilisation de Flexbox pour aligner les éléments et centrer la carte dans la page.

Les media queries m'ont permis d'adapter l'affichage aux écrans mobiles, tablettes et ordinateurs. J'ai aussi utilisé des unités relatives comme `rem` afin de rendre les dimensions et les textes plus flexibles.
