# Frontend Mentor — Défis

Ce dépôt regroupe mes différents projets réalisés dans le cadre des défis proposés par **Frontend Mentor**.

L'objectif est de pratiquer et d'améliorer progressivement mes compétences en développement web à travers des projets concrets.

## 📁 Organisation du projet

Le dépôt est organisé en trois parties principales :

### 📚 `DOCUMENTATION/`

Ce dossier contient la documentation fournie par Frontend Mentor pour chaque défi.

Chaque défi possède son propre fichier :

```text
DOCUMENTATION/
├── DEFIS_1
├── DEFIS_2
├── DEFIS_3
└── ...
```

Ces fichiers servent de référence pendant la réalisation des projets.

### 💻 `DEFIS_X/`

Chaque défi possède son propre dossier de développement.

```text
DEFIS_1/
DEFIS_2/
DEFIS_3/
...
```

Ces dossiers contiennent tous les fichiers nécessaires à la réalisation du projet : HTML, CSS, JavaScript, images, ressources, etc.

Ils constituent les **espaces de travail** utilisés pour développer et tester chaque défi.

### 🌐 `docs/`

Le dossier `docs` contient les **versions finales des défis**.

Il est utilisé pour publier les projets avec **GitHub Pages**. Les fichiers présents dans ce dossier correspondent donc aux versions prêtes à être mises en ligne.

Le lien généré par GitHub Pages peut ensuite être utilisé pour présenter et soumettre le projet à Frontend Mentor.

## 🔄 Fonctionnement

Pour chaque nouveau défi :

1. La documentation est ajoutée dans `DOCUMENTATION/`.
2. Un dossier `DEFIS_X/` est créé pour développer le projet.
3. Le projet est réalisé et testé.
4. Une fois terminé, la version finale est placée dans `docs/`.
5. Le projet est publié avec GitHub Pages.
6. Le lien du site peut être envoyé à Frontend Mentor pour valider le défi.

### 🛠️ Technologies

Selon les projets, différentes technologies peuvent être utilisées, notamment :

* HTML5
* CSS3
* JavaScript

## 🎯 Objectif

Ce dépôt me permet de **suivre ma progression en développement web**, de conserver mes différents projets et de construire progressivement un portfolio à travers les défis Frontend Mentor.

Chaque nouveau défi représente une nouvelle occasion d'apprendre, de pratiquer et d'améliorer mes compétences.
