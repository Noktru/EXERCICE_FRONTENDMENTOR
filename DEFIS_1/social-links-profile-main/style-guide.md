# Guide de style front-end

## Mise en page

Les maquettes ont été créées aux largeurs suivantes :

- Mobile : 375px
- Desktop : 1440px

> 💡 Ce ne sont que les tailles de design. Assurez-vous que le contenu est responsive et qu’il respecte les exigences WCAG en testant la pleine gamme de tailles d’écran, de 320px jusqu’aux grands écrans.

## Couleurs

- Vert : hsl(75, 94%, 57%)

- Blanc : hsl(0, 0%, 100%)

- Gris 700 : hsl(0, 0%, 20%)
- Gris 800 : hsl(0, 0%, 12%)
- Gris 900 : hsl(0, 0%, 8%)

## Typographie

### Corps du texte

- Taille de police (paragraphe) : 14px

### Police

- Famille : [Inter](https://fonts.google.com/specimen/Inter)
- Graisses : 400, 600, 700

Le fichier de design de ce défi inclut aussi un système de design de base pour vous aider à construire une solution plus précise plus rapidement.
